# Fridge Note Line

One funny passive-aggressive note a smart fridge leaves for its owner, written for the [Notes From a Passive-Aggressive Fridge](https://make.fun/bounty/u-motasimfuad-notes-from-a-passive-aggressive-fridge-83c00ad7) bounty on make.fun.

`main.ts` (Node 22, standard library only) writes a single dry, petty, one-line note to `/output/entry.txt` — a smug fridge counting how long its owner stared inside, and what the pickles witnessed.

## Run

```sh
node main.ts
cat /output/entry.txt
```
